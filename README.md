# Filmcase Uploader

اپ اندرویدی فارسی برای مدیریت صف لینک‌ها و اتصال شخصی به Boxera.

## نسخه 1.0.1
- رفع تعریف تکراری تابع اعتبارسنجی اتصال که مانع کامپایل می‌شد.
- اصلاح عملکرد افزودن یک نسخه دیگر از لینک به صف.

## امکانات فعلی
- صفحه عیب‌یابی اتصال شامل اعتبارسنجی ساختار URL، DNS، ارتباط HTTPS و پاسخ واقعی `/auth/me`
- تشخیص جداگانه توکن نامعتبر (401)، مجوز ناکافی (403)، مسیر اشتباه (404)، خطاهای سرور، DNS و SSL
- خروجی گزارش عیب‌یابی بدون درج مقدار توکن
- رابط فارسی RTL با تم تیره و رنگ نارنجی
- ورود توکن شخصی Boxera از بخش تنظیمات
- ذخیره توکن با Android Secure Storage
- نمایش/مخفی‌کردن و حذف توکن ذخیره‌شده
- بررسی واقعی اعتبار توکن با `GET /auth/me`
- افزودن لینک تکی یا گروهی، حذف لینک‌های نامعتبر و تکراری
- چسباندن لینک از کلیپ‌بورد، ساخت و مدیریت پوشه‌ها
- ذخیره محلی صف و تاریخچه
- بررسی لینک با HTTP HEAD و خواندن Content-Length و Content-Type در صورت پشتیبانی سرور
- گردش‌کار GitHub Actions برای تحلیل و ساخت APK نسخه Release

## اتصال Boxera
- آدرس پایه پیش‌فرض: `https://boxera.ir/api`
- احراز هویت با هدر `Authorization: Bearer <token>`
- اعتبارسنجی توکن از مسیر `GET /auth/me`

## وضعیت قابلیت آپلود
این نسخه هنوز انتقال واقعی فایل به Boxera را پیاده‌سازی نکرده است. بررسی لینک با HTTP HEAD صرفاً اطلاعات اولیه لینک را می‌خواند و به معنی آپلود فایل نیست. مسیرهای init، انتقال واقعی بایت‌ها با هر دو پروتکل S3 multipart و TUS، ثبت ETag و تکمیل نشست، ثبت ویدئو و پایش پردازش باید قبل از فعال‌کردن آپلود در اپ تکمیل شوند. برنامه نباید تا آن زمان وضعیت موفقیت آپلود نمایش دهد.

## امنیت توکن
توکن شخصی در Android Secure Storage دستگاه ذخیره می‌شود و داخل سورس یا GitHub قرار نمی‌گیرد. با این حال، مستندات Boxera توصیه می‌کنند توکن فقط روی سرور نگهداری شود؛ ذخیره مستقیم در موبایل ریسک استخراج توکن از دستگاه را دارد. این نسخه برای استفاده شخصی محلی در نظر گرفته شده است.

## ساخت APK
با Push یا Pull Request روی شاخه `main`، GitHub Actions پروژه Flutter را آماده، تحلیل و APK نسخه Release را می‌سازد. خروجی از بخش Actions و قسمت Artifacts قابل دریافت است.

برای ساخت نسخه ریلیز، تگ نسخه (مثلاً `v1.0.1`) را Push کنید؛ علاوه بر بیلد، یک GitHub Release با فایل `filmcase-uploader-v1.0.1.apk` ساخته و منتشر می‌شود. APK ریلیز فعلاً با کلید دیباگ امضا می‌شود و برای نصب شخصی مناسب است.

## اجرای محلی
```bash
flutter create --platforms=android --org ir.filmcase .
flutter pub get
flutter run
```

پیش‌نیازهای بیلد اندروید روی سیستم شخصی:
- JDK 17 نصب باشد و `JAVA_HOME` به همان مسیر اشاره کند (JRE 8 کافی نیست).
- Android SDK Build-Tools 36.0.0 و NDK 28.2.13676358 (نسخه پیش‌فرض Flutter) نصب باشند.
- اگر دسترسی به `dl.google.com` برای مخازن Maven محدود است، از میرور (مثل `maven.aliyun.com/repository/google`) در `android/settings.gradle.kts` و `android/build.gradle.kts` استفاده کنید.

اگر فضای دیسک یا ابزار بیلد محلی در دسترس نیست، ساخت APK را به GitHub Actions بسپارید؛ فایل خروجی در Artifacts اجرای Workflow با نام `filmcase-uploader-android` قرار می‌گیرد.
