# Filmcase Uploader

اپ اندرویدی مدیریت آپلود Filmcase و Boxera با رابط فارسی.

## قابلیت‌های برنامه
- دو روش اتصال: مستقل با توکن Boxera و اتصال از طریق بک‌اند Filmcase
- تنظیمات آدرس API، توکن، تنظیمات اتصال و محدودیت صف
- افزودن لینک تکی و گروهی (هر لینک در یک خط)
- ایجاد و انتخاب پوشه مقصد
- نمایش تاریخچه، صف، حجم فایل‌ها و فضای مصرفی/باقی‌مانده
- طراحی رابط RTL فارسی و تم تیره با تأکید نارنجی

## وضعیت اتصال Boxera
اطلاعات تأییدشده فعلی: پایه API برابر با `https://boxera.ir/api`، احراز هویت Bearer و معرفی مسیر `POST /uploads/init`.
ساختار دقیق درخواست init، روش دریافت فایل از URL، endpoint انتقال فایل، پاسخ‌ها و endpoint وضعیت هنوز باید از مستندات رسمی تکمیل شود. برنامه نباید وضعیت موفقیت یا فضای مصرفی را حدس بزند. تا زمان تکمیل قرارداد API، عملیات واقعی با پیام «نیازمند تکمیل تنظیمات API» متوقف می‌شود.

## اجرا
پروژه با Flutter/Dart طراحی شده است. پس از نصب Flutter:
```bash
flutter pub get
flutter run
```

توکن واقعی را در سورس، فایل تنظیمات یا GitHub قرار ندهید. نسخه نهایی باید آن را در Android Keystore از طریق secure storage نگه دارد.
