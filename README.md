# Filmcase Uploader

اپ اندرویدی فارسی برای آماده‌سازی و مدیریت صف لینک‌های ویدیویی Filmcase و Boxera.

## امکانات پیاده‌سازی‌شده
- حالت مستقل Boxera و حالت اتصال از طریق بک‌اند Filmcase
- تنظیم آدرس API، توکن اختصاصی Boxera و آدرس بک‌اند
- نگهداری توکن با Flutter Secure Storage (نه SharedPreferences)
- افزودن لینک تکی یا گروهی؛ هر لینک در یک خط
- حذف لینک‌های نامعتبر و URLهای تکراری
- محدودیت تعداد لینک در هر دسته
- چسباندن لینک‌ها از کلیپ‌بورد
- ساخت پوشه، انتخاب پوشه مقصد و حذف پوشه خالی
- انتقال آیتم بین پوشه‌ها، کپی لینک، افزودن مجدد به صف و حذف از فهرست
- ذخیره محلی صف و تاریخچه پس از بستن برنامه
- بررسی لینک با HTTP HEAD و دریافت Content-Length و Content-Type در صورت ارائه سرور
- محاسبه مجموع حجم لینک‌های بررسی‌شده و نمایش تعداد حجم‌های نامشخص
- تنظیم تعداد بررسی‌های هم‌زمان و سقف آپلود هم‌زمان برای استفاده در مرحله اتصال API
- داشبورد فارسی، RTL و تم تیره با رنگ نارنجی
- گردش‌کار GitHub Actions برای ساخت APK و انتشار آن به‌صورت Artifact

## مواردی که هنوز به مستندات رسمی Boxera وابسته‌اند
اطلاعات تأییدشده فعلی: پایه API برابر با `https://boxera.ir/api`، احراز هویت Bearer و معرفی مسیر `POST /uploads/init`.

برای آپلود واقعی از URL، نمایش درصد و سرعت انتقال، زمان باقی‌مانده، توقف/ادامه، وضعیت پردازش و فضای مصرفی/باقی‌مانده حساب باید قرارداد رسمی endpointها، ساختار request/response، پروتکل انتقال فایل و API سهمیه دریافت شود. این موارد عمداً شبیه‌سازی نشده‌اند و برنامه نباید نتیجه موفقیت یا فضای مصرفی جعلی نمایش دهد.

بررسی اندازه لینک‌ها با HTTP HEAD انجام می‌شود. برخی میزبان‌ها HEAD را مسدود می‌کنند یا Content-Length نمی‌فرستند؛ در این حالت حجم «نامشخص» باقی می‌ماند. این قابلیت به معنی دانلود یا آپلود فایل نیست.

## ساخت APK
با هر Push یا Pull Request روی شاخه main، GitHub Actions پروژه Flutter را آماده، تحلیل و APK نسخه Release را می‌سازد. فایل خروجی از بخش Actions همان اجرای Workflow و قسمت Artifacts قابل دریافت است.

## اجرای محلی
```bash
flutter create --platforms=android --org ir.filmcase .
flutter pub get
flutter run
```

## امنیت
- توکن واقعی را در سورس، فایل تنظیمات یا GitHub قرار ندهید.
- حالت مستقل توکن را در Android Secure Storage نگه می‌دارد.
- در حالت Filmcase، توکن Boxera باید فقط روی سرور Filmcase بماند و اپ صرفاً با API بک‌اند ارتباط داشته باشد.
- تا زمان تکمیل مستندات، اتصال واقعی و عملیات آپلود فعال تلقی نمی‌شود.
